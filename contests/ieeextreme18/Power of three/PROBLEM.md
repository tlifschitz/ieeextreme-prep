# Power of three

**IEEEXtreme 18.0** · Time limit: 1000 ms · Memory limit: 256 MB

**CS Academy:** <https://csacademy.com/ieeextreme-practice/task/power-of-three/>

You are given a positive integer $N$. Your task is to determine if there exists a nonnegative integer $x$ such that $3^x = N$. If such an integer exists, print $x$; otherwise, print $-1$.

# Input

The first line contains one integer $N$.

# Output

If there exists a nonnegative integer $x$ such that $3^x = N$, print $x$. Otherwise, print $-1$.

# Constraints and notes

- $N$ is a nonnegative number with at most $10^7$ digits.
- The time limit is the same for all languages.
- The test cases are grouped. In order to get the points for a test group you need to pass all tests in that group.

## Examples

### Example 1

Input:
```
1
```

Output:
```
0
```

### Example 2

Input:
```
21
```

Output:
```
-1
```

### Example 3

Input:
```
243
```

Output:
```
5
```
